# 02 — Component Registry

Navigation (utility bar, mega menu, mobile drawer, account menu), six button variants, services/cards/pricing/evidence/status modules, forms and validation, loading/empty/error, dialogs, tables and charts, tabs, accordions, carousels (pause + keyboard), notifications, consent, onboarding wizard, organization selector, customer/staff sidebar, subscription, checkout and service requests.

One master component per semantic role. Each has Figma node ID, props, state table, accessibility notes and implementation path; missing node IDs remain tracked design tasks rather than invented links. Radix/shadcn primitives are preferred for accessible interactions.
