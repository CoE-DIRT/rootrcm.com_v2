# Getting started

1. Clone `https://github.com/CoE-DIRT/rootrcm.com_v2`.
2. Read README, AGENTS, LICENSE, SECURITY and the Figma master page.
3. Install compatible Node LTS, run `npm install`, then `npm run dev`.
4. Use `cp .env.example .env.local` on Unix shells or `Copy-Item` in PowerShell. Leave all integrations disabled until isolated V2 projects are approved.
5. Open a scoped GitHub Issue; implement on a feature branch; submit PR with Figma node link, EN/ES+theme tests and screenshots.
6. Never publish PHI or secrets in GitHub, Figma, or AI agent prompts.
