# Frequently asked questions

**Is ROOT V2 replacing the live website now?** No. V1 remains untouched until an approved cutover.

**Is this repository an open-source project?** Not under the provisional LICENSE. Public visibility does not grant reuse rights.

**Is Appwrite already connected to this V2 code?** Only disabled interface/adapters are scaffolded. Independent project setup and security tests are required.

**Are the workspace figures real claims or customers?** No. Fixtures are synthetic and must remain so for open review.

**Can I publish the Figma reference as a live healthcare system?** No. Design parity, OAuth, tenant isolation, security, legal and operational QA must pass first.

**Can I file an issue containing patient or client details?** Never. Use de-identified reproduction steps and request a secure channel for sensitive disclosures.
