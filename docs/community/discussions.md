# Discussion categories and moderation

Once **Settings > General > Discussions** is enabled, create categories:
- Announcements — maintainer posts only
- Ideas & UX — Figma, navigation, accessibility and product feedback
- Q&A — public developer questions
- Integrations — sandbox contract design and architectural discussion
- Show and tell — synthetic previews and QA evidence

Link discussions to GitHub Issues only when a scoped action is agreed. Never discuss live clients, patient information, private code/keys or competitor confidential material. Follow CODE_OF_CONDUCT.md and SECURITY.md.
