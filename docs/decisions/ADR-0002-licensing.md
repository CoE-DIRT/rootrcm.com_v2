# ADR-0002 — Public repository and licensing

**Status:** Provisional; legal/founder confirmation required before main-branch adoption.
**Context:** ROOT V2 became public on October 29, 2026. The code contains proprietary brand content, design assets and planned commercial application logic. Public != open source.

**Decision proposal:** Keep original ROOT materials all-rights-reserved unless ROOT explicitly approves MIT, Apache-2.0, AGPL-3.0 or a dual-license model. LICENSE reflects that interim posture. Respect third-party license obligations for Next.js, React, Figma assets, etc. Do not republish proprietary customer data or licensed stock art.

**Approval question:** Should implementation code be open-sourced separately from ROOT logos, commercial copy, fixtures and private integration adapters? Record an explicit affirmative decision before granting reuse rights.

**Control:** Include license audit and third-party notices review in release checklist.
